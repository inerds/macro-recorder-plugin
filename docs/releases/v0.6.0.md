# Macro Recorder v0.6.0

**Turn your repetitive edits into one-click macros — record, then apply to any layer.**

Third shared build. Unzip it, add the folder as a plugin in Lottie Creator,
and you're recording. Existing macros carry over unchanged.

## Highlights

- **Stagger works on macros without keyframes.** Set a stagger on a static
  edit and each selected layer is delayed in turn: its in point and its own
  animation move together, so a layer that already animates starts later as
  a whole. With At playhead the first layer's in point lands on the current
  frame. The delay runs once per run, layers move in selection order, and a
  layer whose new in point would reach its out point is skipped with a note.
- **Stagger tells you when it can't apply.** A run with nothing selected, or
  a single selected layer, now says so instead of quietly ignoring the
  value.
- **A calmer macro list.** One 4px gap on every row, the row keys sit
  together, the dotted leader between name and count is gone, and the whole
  row lifts when you hover with the name lit like the catalogue number.
- **Corners on three sizes.** Cards, menus and dialogs share one radius,
  keys another, and recessed fields and lists a third, across the whole
  panel.

## Fixed in this build

- The rows above and below an open macro card keep their separators, so the
  card no longer reads as nested between them.
- Rounded corners on the menu, the toast, text fields and the cream keys
  were each slightly off the panel's scale.

## Known limitations (host plugin API)

Some things the host doesn't yet expose to plugins. These record fine, but
they can't fully replay — the panel notes it when they don't:

- Nesting layers into a new scene: replay creates the scene layer, but can't
  move layers into it.
- Color tokens: replay applies the resolved color, not the token binding.
- Per-fill opacity, rectangle corner roundness, and timeline keyframe
  selection ("Add selected").

These light up automatically as the host's API grows.
