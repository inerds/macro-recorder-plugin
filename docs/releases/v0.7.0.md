# Macro Recorder v0.7.0

**Turn your repetitive edits into one-click macros — record, then apply to any layer.**

Fourth shared build. Unzip it, add the folder as a plugin in Lottie Creator,
and you're recording. Existing macros carry over unchanged.

## Highlights

- **Nesting layers now really nests them.** Creator gives no plugin a way to
  move a layer into a scene, so the plugin rebuilds each selected layer inside
  the new scene, puts the new scene where the first layer was, and removes the
  originals. The note says so: "nested the 3 selected layers (rebuilt inside
  the new scene — Creator can't move them)". An image layer stays where it is,
  with its own note. Undo takes one step per rebuilt layer.
- **Scene settings record and replay.** Size, background (a transparent one
  included), frame rate, duration, and the scene name are captured. Playback
  applies them to the active scene once per run, whatever you have selected.
  Simplify folds a setting you changed several times into one step.
- **More edits record.** A mask's mode, a gradient switched between linear
  and radial, and a scene switch during a recording each add a step. The
  scene-switch step names the change and never replays.
- **Re-created groups arrive whole.** A group the replay rebuilds holds its
  shapes, flags, strokes, masks, and trim paths. It used to arrive empty and
  report success.
- **Playback notes tell adjustments from skips.** A stagger that worked says
  "3 steps adjusted"; only a step that could not apply counts as skipped.
  Every note speaks Creator's language, and the notes toast stays for eight
  seconds.
- **The panel stays reachable.** It opens on the demo engine and says so when
  the plugin engine cannot be reached, and it reconnects when the first
  handshake is lost. A failed save shows the reason Creator gave.
- **A separate development build.** It installs as **Macro Recorder (dev)**
  with its own macro store, so testing never touches the macros you saved
  with the released build.

## Fixed in this build

- Playing a macro with shapes in the selection now skips the shapes and says
  so. Macros replay onto layers.
- A macro that adds an image layer now says it cannot re-create the layer,
  because a recording holds no image asset.
- Adding or replacing a fill or a stroke no longer fails outright when the
  recording carried a paint opacity.
- Removing or replacing a text layer's fill or stroke now works. The step
  used to miss, then claim it had added the new paint beside the old one.
- A macro that shifts a keyframed layer now measures the target against the
  value you can see at the playhead, so a relative move lands where you
  expect.
- Keys that are off say why when you reach them with the keyboard, the deck's
  Stop key works during playback, a paused run scrolls its Continue/Stop into
  view, and the screen reader hears one announcement at the start and the end
  of a run.
- Clearer wording throughout: "Add all keyframes", "Discard recording",
  "Duration 30 frames", one wording for every failure toast, and "Rebuilds
  the scene" instead of "scene script".
- Higher contrast on the red keys, the running and pending steps, the import
  placeholder and the warning box; a hairline edge on light Creator themes;
  the deck's smallest readouts never drop under 9 px.
- The inline confirmation gives focus back to the control you came from when
  you dismiss it.
- The panel's surround follows Creator's own light or dark setting, and the
  panel accepts theme updates and engine replies from Creator's own window
  only.

## Known limitations (host plugin API)

Some things the host doesn't yet expose to plugins. These record fine, but
they can't fully replay — the panel notes it when they don't:

- Nesting rebuilds copies: each nested layer gets a new id, and an image
  layer cannot be rebuilt because the recording holds no image asset.
- Color tokens: replay applies the resolved color, not the token binding.
- Per-fill opacity, rectangle corner roundness, motion-path bezier handles,
  and timeline keyframe selection ("Add selected").

These light up automatically as the host's API grows.
